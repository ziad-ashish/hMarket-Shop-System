# تك ماركت — نظام إدارة محل موبايلات وأدوات كهربائية

نظام سطح مكتب يعمل محليًا (PyWebView + Flask + SQLite) لإدارة محل يبيع الموبايلات والإكسسوارات والأدوات الكهربائية ويقدّم خدمة الصيانة. مبني على نظام إدارة صيدلية، وتم تحويل منطق العمل بالكامل لطبيعة المحل.

## التشغيل

شغّل `run.bat` (يتحقق من Python والمتطلبات ثم يفتح التطبيق). حسابات البداية:

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `admin` | `admin123` | مدير النظام |
| `supervisor` | `123456` | مشرف المحل |
| `cashier` | `123456` | بائع |
| `technician` | `123456` | فني صيانة |

غيّر كلمات المرور من الإعدادات بعد أول دخول. لبدء قاعدة بيانات فارغة احذف ملف `shop.db` قبل التشغيل (تُنشأ بيانات تجريبية بالجنيه المصري عند أول تشغيل).

## الوحدات

- **الأصناف والمخزون:** موبايلات، إكسسوارات، أدوات كهربائية، مستلزمات كهرباء، قطع غيار، خدمات. وحدات بيع وشراء مختلفة (لفة/متر، كرتونة/قطعة)، سعر جملة، باركود، جرد، حد إعادة الطلب.
- **أجهزة بأرقام IMEI / Serial:** كل جهاز يُسجَّل برقمه، ويُباع برقمه، وتُحسب نهاية الضمان تلقائيًا. رصيد الجهاز = عدد الوحدات المتاحة. مسح IMEI بالباركود في نقطة البيع يضيف الجهاز مباشرة.
- **نقطة البيع:** بحث بالاسم/الماركة/الباركود/IMEI، أسعار جملة، عروض، آجل بدين مرتبط بالعميل، نقاط ولاء، خدمات (تركيب اسكرين، نقل بيانات...).
- **الصيانة:** إيصال استلام، حالات (استلام ← فحص ← موافقة العميل ← إصلاح ← جاهز)، فني، قطع غيار، عربون، تسليم بفاتورة، وصيانة تحت الضمان بدون مقابل (تُخصم القطع بدون فاتورة).
- **الضمان:** بحث برقم IMEI أو الفاتورة أو تليفون/اسم العميل، مع سجل صيانة الجهاز.
- **المشتريات والموردون:** استلام أمر الشراء بأرقام IMEI للأجهزة، وتكلفة متوسطة مرجحة للأصناف العادية.
- **التقارير:** مبيعات، أرباح بتكلفة الوحدة وقت البيع، أعمار مخزون الأجهزة (الراكد)، دوران المخزون، أعمار الديون، ربحية العملاء، أداء السائقين، تصدير Excel.
- **أخرى:** فواتير وإلغاء، ديون، حسابات وصندوق، موظفون ورواتب، توصيل وتتبع، نسخ احتياطي، سجل تدقيق.

## الأدوار

مدير النظام (كل شيء) • مشرف المحل (أصناف، عملاء، موردون، تقارير، صيانة) • بائع (بيع، عرض الأصناف، فواتير، صيانة) • فني صيانة (تذاكر الصيانة وعرض القطع).

## هيكل المشروع

- `main.py`: نافذة سطح المكتب وخادم Flask المحلي • `api.py`: قاعدة البيانات ومنطق العمل • `shop_ops.py`: أساسيات IMEI والمسودات • `routes.py` و`server_auth.py`: واجهة REST والصلاحيات
- `src/js/data.js`: طبقة الاتصال • `src/js/pages/`: الشاشات (منها `repairs.js` و`warranty.js`) • `src/css/`: التصميم
